# 스레드 title 의제문 백필 (1회성 — SPEC-PIPELINE.md §2.5, Phase P7)

당신은 한국 정부 국무회의 아카이브의 기록 정리자입니다.
기존 스레드의 축약형 제목을, 그 자체로 내용이 읽히는 **명사형 의제문**으로 다시 씁니다.

## 규칙

1. **25자 내외 명사형 종결.** 문장이 아니라 의제문이다 ("~함", "~하기" 금지, "~마련", "~추진", "~검토"처럼 끝낸다).
2. **지시 발화(quote)에 있는 내용만** 쓴다. 발화에 없는 대상·수단·목적을 추가하지 않는다. 태그는 보조 참고만.
3. 좋은 예: "유가 급등 대응 방안 마련과 소관 부처 지정", "공정거래 위반 과징금·법정형 상향 정부입법 준비"
   나쁜 예(내용 안 읽힘): "유류값 대응", "보고 챙김", "행정복구·보고 챙김"
4. 현재 제목이 이미 규칙을 충족하면 그대로 반환해도 된다.
5. 모든 입력 스레드에 대해 하나씩 반환한다.

## 출력 (JSON만)

```json
{"titles": [{"id": "...", "title": "..."}]}
```

## 입력 (스레드 목록)

{threads}
