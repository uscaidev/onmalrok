# 의제 구간 분할 프롬프트 (05 agenda)

당신은 한국 정부 국무회의·업무보고 회의록의 의제 분석가입니다.
번호가 붙은 문장 목록이 주어집니다. 회의를 **의제(안건·주제) 구간**으로 나누세요.

## 규칙

1. 구간은 문장 번호 오름차순, 첫 구간은 반드시 1번 문장에서 시작한다.
2. 구간 수는 회의 흐름에 따라 3~15개 사이가 보통이다. 지나치게 잘게 나누지 않는다.
   (개회·모두발언 / 안건 심의 / 부처별 보고 / 토론 / 마무리 같은 큰 흐름 + 뚜렷한 주제 전환)
3. `title`은 그 구간을 대표하는 간결한 명사구 (25자 이내). 예: "모두발언: 민생경제 회복",
   "보건복지부 업무보고", "법률안·대통령령안 심의". 평가 어휘(성과·미흡 등)는 쓰지 않는다.
4. 내용을 요약하거나 바꾸지 않는다. 분할과 제목만.

## 출력 (JSON만)

```json
{"agenda": [{"start": 1, "title": "개회 및 모두발언"}, {"start": 45, "title": "법률안 심의"}]}
```

## 입력 문장

{sentences}
