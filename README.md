# 온말록 (Onmalrok)

> 국무회의·국민업무보고 영상 아카이브 — 발언을 문장 단위로 기록하고, 언제나 원문 영상으로 되돌아갑니다.

**https://onmalrok.vercel.app**

KTV 유튜브에 올라오는 국무회의·국민업무보고 영상을 사람 개입 없이 수집해, 자막을 문장 단위로 분할·교정하고 검색·구간 재생이 가능한 형태로 공개하는 아카이브입니다.

## 무엇을 할 수 있나

- **검색** — 전체 회의의 발언을 문장 단위로 검색하고, 해당 구간부터 바로 재생
- **시청** — 유튜브 임베드 + 자막 패널로 회의 전체를 타임스탬프와 함께 열람
- **부처 브리핑** — 회의×부처로 자른 지시사항·답변사항 발췌를 개조식(□/○)으로 복사 (AI 추출 초안 · 원문 대조 필수)
- **국정과제 트래커** — 123대 국정과제별로 관련 발언과 마지막 보고 시점을 시간순으로 추적
- **오픈데이터** — 모든 데이터는 이 저장소의 `/data` JSON 그대로. Git이 곧 DB이자 덤프

## 원칙

**"연결은 해석이 아니라 각주다."** 아카이브는 기록을 보존하고 판단은 사용자가 합니다.

- 모든 연결에는 근거 배지, 모든 파생물의 종착점은 원문 영상 구간
- 평가하지 않습니다 — 성과/실패가 아니라 상태(보고됨 · 예정 · 후속 대기 N일째)만 표기
- AI가 만든 모든 것에는 라벨을 붙입니다 (`AI 요약`, `화자 AI 추정`)

## 구조

두 트랙이 `/data` JSON 계약 하나로만 만납니다.

| 트랙 | 내용 | 설계서 |
|------|------|--------|
| A · 파이프라인 | Python — KTV RSS 감지 → yt-dlp 자막 폴링 → 문장 분할 → LLM 교정(배치 전용) → 색인 생성. GitHub Actions로 일 3회 자동 실행 | [SPEC-PIPELINE.md](SPEC-PIPELINE.md) |
| B · 웹 앱 | Next.js (App Router) + 정적 JSON, Vercel 배포. 클라이언트 검색(MiniSearch), DB 서버 없음 | [SPEC.md](SPEC.md) |

원문 자막(`text_raw`)은 어떤 경우에도 삭제하지 않으며, 실시간 LLM 처리는 하지 않습니다(배치만).
